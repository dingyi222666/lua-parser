This is a draft acceptance traceability matrix for the current coordinated lua-parser wave. It maps parent acceptance areas to the task evidence that exists now, the intended verification evidence that must be produced later, and the current evidence status.

TASK-406 is a docs-only stale-status refresh of this draft (done-task accuracy for closed work such as TASK-170/TASK-176/TASK-138/TASK-140 and honest blocked wording for the final chain). Final pass/fail claims remain reserved for TASK-105 and TASK-106 after serialized verification.

Status labels:

- `Done task evidence`: scoped task metadata or docs exist, but command-level acceptance may still be pending.
- `Pending TASK-043`: intended Gradle/test evidence has not been produced by the current serialized verification gate.
- `Pending follow-up`: a current follow-up task still needs implementation, documentation, or review before TASK-043 can verify it.
- `Blocked`: the parent acceptance area cannot be accepted from current evidence.
